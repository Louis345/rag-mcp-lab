# Personal RAG Retrieval Lab

A small, dependency-free lexical retrieval exercise. `retriever.mjs` ranks documents by the number of distinct query terms present; `retrieve.mjs` runs six fixed test cases and reports top-1 accuracy. This baseline measures word overlap, not semantic understanding.

Run with Node.js:

```bash
node retrieve.mjs
```

The retirement-account document is entirely synthetic. The investment-policy document was confirmed by the project owner as a non-sensitive practice document. Do not add real customer, employer, credential, or personal financial data to this repository.

Private learning notes in `PROGRESS.md` and the original retirement-account sample are deliberately excluded from this GitHub copy.
